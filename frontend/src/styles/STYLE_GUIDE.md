# UI Style Guide (Frontend Restaurantes)

## Paleta principal
- Acento: naranja/ambar
  - Boton principal: `bg-gradient-to-r from-orange-500 to-orange-600`
  - Hover: `hover:from-orange-400 hover:to-orange-500`
- Fondos: `bg-white`, `bg-slate-50`
- Bordes: `border-slate-200`
- Texto principal: `text-slate-900`
- Texto secundario: `text-slate-600`
- Error: `text-rose-500`, `bg-rose-50`

## Tipografia
- Fuente base: `Sora` (Google Fonts)
- Pesos sugeridos: 400, 500, 600, 700

## Componentes base
- Card: `rounded-2xl border border-slate-200 bg-white shadow-sm`
- Input: `rounded-xl border border-slate-200 bg-slate-50 px-4 py-3 text-sm`
- Select: `rounded-xl border border-slate-200 bg-white px-4 py-3 text-sm`
- Boton secundario: `rounded-full border border-slate-200 text-slate-600`
- Badge estado: `rounded-full px-3 py-1 text-xs font-semibold`

## Layout y spacing
- Secciones: `space-y-6`
- Grids: `grid gap-4 md:grid-cols-2 xl:grid-cols-3`
- Contenedor general: `min-h-screen bg-slate-50 text-slate-900`

## Reglas
- No usar azul como color principal.
- Mantener tipografia limpia y jerarquia clara.
- Acciones principales en naranja/ambar; acciones secundarias en gris.
